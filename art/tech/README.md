# 科技材质重绘

本套为本地逐像素绘制的正式游戏资源。源图形、配色和模型引用定义在 `tools/redraw_tech_textures.py`；无需联网或图像 API。

## 范围

- E、D、C、B、A、S、EX 七级科技枪和能量盾，按现有 TechData.Rank 切换外观。
- 十种枪械模块、十三种护盾模块及两类默认模块。
- 七级金属的锭、板、粉末、废料，以及控制核心、回收碎片、齿轮、电路、光学组件和能源核心。
- 七级机械知识手册、研究消耗品、便携电容和幻能块。
- 黑洞种子、空载／装载磁约束容器、微型奇点。
- 14 种科技机器的面板、侧面、顶部、底部，以及微型宇宙发电机的运行状态。
- 护盾供氧条的独立图标图集。

共 176 张 PNG：111 张物品贴图、64 张机器贴图、1 张 HUD 图集。物品和方块主要为 16×16，枪盾、奇点链物品和手册使用 32×32；HUD 图集为 32×16。

## 外观

深色机壳、金属倒角、分级能源色。锭、板、粉和废料使用不同轮廓；弹药、枪管、消音器和瞄具具有不同结构；护盾模块以剑、弹体、爆炸、火焰、菱形和环境图标区分功能。

材料已经包含最终配色，客户端不再叠乘原来的整图染色。所有新模型均使用模组自有贴图；物品数据生成器同步保留等级变体、独立模块纹理与机器方块继承关系。

## 查看与维护

- `preview.png`：枪盾等级、材料及奇点链摘要。
- `overview.png`：全部贴图总览。
- `machines.png`：使用实际三面贴图绘制的等距预览；不是游戏截图。
- `before.png`：修改前物品材质概览。
- `originals.zip`：首次替换前已有贴图与模型的备份。
- `manifest.json`：本次输出路径、尺寸及 SHA-256 清单。

在项目根目录执行：

```powershell
python tools/redraw_tech_textures.py
python tools/redraw_tech_textures.py --check
```

需要 Pillow。重新执行绘制会覆盖清单中的正式资源；`--check` 只检查资源及模型引用。`originals.zip` 不会在重复执行时被覆盖。

## 验证

PNG 格式、135 个科技模型引用、成品 JAR 的贴图内容均已核对。相关 8 项 JUnit 资源测试通过，`jar` 和 `reobfJar` 通过。本轮未运行游戏客户端作实机视觉验收。

产物：`build/libs/transcend-1.1.jar`。
